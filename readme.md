# 🎯 Challenge 74 (Furniture Store System)

## 📝 فكرة المشروع

`حساب فاتورة شراء الأثاث.`

## 📥 المدخلات

- اسم العميل.
- نوع المنتج.
- سعر القطعة.
- الكمية.
- خدمة التركيب؟ (Yes / No)

## 📌 المطلوب

## إذا اختار خدمة التركيب:

- أضف 500 جنيه.

- إذا تجاوزت الفاتورة 25000 جنيه:

- خصم 12%.

## ⚠️ الشروط

- السعر أكبر من صفر.
- الكمية أكبر من صفر.

## 📤 المخرجات

- Customer
- Product
- Quantity
- Installation
- Total
- Discount
- Final Price

## 💡 مثال

- Wardrobe
- Price = 12000
- Quantity = 3
- Installation = Yes
